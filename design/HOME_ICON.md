# Иконка главной вкладки

Идея: открытая книга со скобками кода на страницах. Концепт создан встроенным генератором изображений и адаптирован в нативный VectorDrawable для читаемости на 28dp, ровного цвета и чётких краёв на любой плотности экрана.

Ресурс: app/src/main/res/drawable/ic_home_learning.xml. Использование: первый пункт NextCodeBottomMenu, описание для доступности «Обучение». Компилятор сохраняет свою прежнюю иконку. Палитра и выделение активного пункта остаются существующими.

Финальный промпт концепта:

Production-ready Android navigation icon, single flat pictogram, square canvas. A clean geometric outline of an open book with a left coding angle bracket on the left page and a right coding angle bracket on the right page. ONLY five or six simple smooth solid strokes. Use ONE uniform opaque vivid violet ink color #B300FF for every stroke. Large smooth rounded stroke ends, very clean mathematical curves, perfectly solid ink with absolutely no speckles, holes, grunge, distressed texture, brush texture, shadows, noise or glow. Transparent empty background, transparent empty book pages, generous clear negative space; all ink strokes are fully opaque. The shape should occupy 70 percent of canvas, centered, suitable at tiny 28px size. No arrow, no roof, no house, no stars, no text, no labels, no words, no border tile, no gradients, no mockup. Flat vector-icon look, smooth antialiased edges. One open-book-with-code icon only, isolated on a genuinely transparent canvas.
