# Задания MVP

Клиент выпускается вместе с backend, содержащим V9__localized_typed_tasks.sql. Полное описание миграции и API: docs/MVP_MIGRATION.md в NextCodeBackend.

Новые типы: MULTIPLE_CHOICE (один/несколько ID вариантов), FILL_BLANK (текст между sentenceBefore/sentenceAfter), CODING (starterCode и programmingLanguage). Сверка перенесена на backend; правильные ответы и решения в GET-ответах отсутствуют. Объяснение возвращается после проверки. При ошибке сети ответ сохраняется на экране и запрос можно повторить; повторное нажатие во время запроса блокируется.

В настройках выбирается активный язык учебного контента. Язык интерфейса остаётся русским. После смены языка заново откройте курс/урок: уже открытые экраны хранят загруженный контент. RU включён по умолчанию, EN выключен до заполнения переводов.

CODING в этой итерации — упражнение на точное воспроизведение эталона, с учётом регистра и внутренних пробелов. Это явно указано на экране. Код не запускается; проверка альтернативных решений требует отдельного исполнителя и тестов.

Для сборки нужны JDK и Android SDK 36: `bash gradlew assembleDebug`. Перед запуском укажите BASEURL вашего backend в core/data/remote/RetrofitClient.kt (для стандартного Android-эмулятора обычно http://10.0.2.2:8080/). На физическом устройстве используйте доступный ему адрес сервера.

Проверка: выбрать курс, открыть теорию, выбрать один/несколько вариантов, отправить неверный и верный ответы, заполнить пропуск, выполнить упражнение с кодом, отключить сеть и повторить запрос, завершить урок. При повторном запросе завершения backend не начисляет XP снова. Demo SQL в backend создаёт отдельный урок со всеми тремя типами.

Совместимость сборки: Foundation выровнен с уже используемым Compose UI до 1.10.6. Исходный Foundation 1.12.0 требовал SDK 37 и AGP 9.1 при настройках проекта SDK 36 / AGP 9.0.1.

## Исправления мобильного сценария

Выбранный курс восстанавливается из `/api/users/me`, без подстановки ID 1 и без локального ID -1. После входа клиент сначала проверяет сессию и загружает профиль; если курса нет, открывается выбор. Ответ профиля от старого входа не может вернуть данные после выхода или смены аккаунта.

Общий обработчик сессии перехватывает 401. Для 403 на обычном ресурсе выполняется дополнительный GET /api/users/me: выход происходит только если проверка профиля тоже отвергает JWT. Ошибки сети/5xx не очищают токен. Ошибка на публичных login/register не завершает другую сессию. При истечении сессии токен и профиль очищаются, история защищённых экранов сбрасывается, открывается вход с пояснением. Нет автоматического продления: пользователь входит повторно.

Завершение урока показывает успех только после ответа backend. При ошибке доступен повтор, кнопка возврата к курсу заблокирована до сохранения. ID урока сохраняется до выхода с экрана результата, поэтому можно вернуться к заданиям. Повторная отправка ранее решённого задания разрешена, а серверная идемпотентность защищает награды. Декоративная панель пяти шагов удалена.

Карточки входа/регистрации сохранили оформление, но получили естественную высоту, прокрутку и отступ под клавиатуру. Минимальная высота полей и основной кнопки допускает рост содержимого при увеличении шрифта.

Проверки: 401, 403 с истёкшим/действующим JWT, ошибки проверки сессии, поздний ответ старого аккаунта, восстановление курса и смена курса на фоне загрузки, повтор завершения урока после ошибки, защита от одновременного завершения и возврат к пройденному заданию. На устройстве отдельно проверить маленький экран, увеличенный шрифт и клавиатуру.

Итоговая проверка мобильных исправлений: assembleDebug и testDebugUnitTest, 20 успешных тестов. Три проверки AuthLayoutTest запускают реальные Compose-формы через Robolectric (Android API 35), уменьшают область до 320×280–300dp и увеличивают шрифт до 200%; проверяют доступность входа, регистрации, переключения между формами и сообщения об истёкшей сессии через прокрутку. Это проверка в тестовой Android-среде, а не запуск на физическом телефоне.
