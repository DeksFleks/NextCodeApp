# Задания MVP

Клиент выпускается вместе с backend, содержащим V9__localized_typed_tasks.sql. Полное описание миграции и API: docs/MVP_MIGRATION.md в NextCodeBackend.

Новые типы: MULTIPLE_CHOICE (один/несколько ID вариантов), FILL_BLANK (текст между sentenceBefore/sentenceAfter), CODING (starterCode и programmingLanguage). Сверка перенесена на backend; правильные ответы и решения в GET-ответах отсутствуют. Объяснение возвращается после проверки. При ошибке сети ответ сохраняется на экране и запрос можно повторить; повторное нажатие во время запроса блокируется.

В настройках выбирается активный язык учебного контента. Язык интерфейса остаётся русским. После смены языка заново откройте курс/урок: уже открытые экраны хранят загруженный контент. RU включён по умолчанию, EN выключен до заполнения переводов.

CODING в этой итерации — упражнение на точное воспроизведение эталона, с учётом регистра и внутренних пробелов. Это явно указано на экране. Код не запускается; проверка альтернативных решений требует отдельного исполнителя и тестов.

Для сборки нужны JDK и Android SDK 36: `bash gradlew assembleDebug`. Перед запуском укажите BASEURL вашего backend в core/data/remote/RetrofitClient.kt (для стандартного Android-эмулятора обычно http://10.0.2.2:8080/). На физическом устройстве используйте доступный ему адрес сервера.

Проверка: выбрать курс, открыть теорию, выбрать один/несколько вариантов, отправить неверный и верный ответы, заполнить пропуск, выполнить упражнение с кодом, отключить сеть и повторить запрос, завершить урок. При повторном запросе завершения backend не начисляет XP снова. Demo SQL в backend создаёт отдельный урок со всеми тремя типами.

Совместимость сборки: Foundation выровнен с уже используемым Compose UI до 1.10.6. Исходный Foundation 1.12.0 требовал SDK 37 и AGP 9.1 при настройках проекта SDK 36 / AGP 9.0.1.
