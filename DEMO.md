# Автономная демонстрация NextCode

`demo` — отдельная Android-сборка для показа продукта без сервера и интернета.
Устанавливается рядом с серверной версией: пакет `dbataev.nextcodeapp.demo`, имя **NextCode Demo**.

## Сборка и установка

Требуются JDK 21 и Android SDK 36:

```bash
bash gradlew assembleDemoDebug testDemoDebugUnitTest
adb install -r app/build/outputs/apk/demo/debug/app-demo-debug.apk
```

Готовый APK также собирается GitHub Actions: артефакт **nextcode-demo**.
Это подписанный отладочным ключом APK для демонстрации, не публикации в магазине.
Серверная версия собирается командой `bash gradlew assembleFullDebug`.

## Сценарий показа

1. Включи авиарежим. Открой **NextCode Demo**.
2. Зарегистрируй локальный аккаунт: например, логин `judge`, пароль `Demo2026`, никнейм `Эксперт`.
   Заранее созданных аккаунтов нет; пустой никнейм заменяется логином.
3. Выбери Java. Доступны два модуля и шесть последовательных уроков:
   вывод текста, переменные, арифметика, условия, циклы и массивы.
4. В каждом уроке есть теория и три задания: выбор ответа, пропуск в строке и редактирование кода.
   В некоторых тестах нужно отметить два ответа. Написание кода проверяется по явно указанному
   эталону; произвольный код не исполняется.
5. Пройди первый урок: появятся 25 XP, серия занятий и первое достижение.
   После третьего урока будет второй уровень. После всего курса — третий уровень и 250 суммарных XP.
6. Открой достижения и профиль. Закрой приложение, запусти снова: аккаунт, выбранный курс и прогресс сохранятся.
7. Выйди и войди тем же логином/паролем. Можно зарегистрировать другой аккаунт для чистого показа.
8. На экранах компилятора и рейтинга показано «Доступно в полной версии продукта».

## Что хранится локально

SQLite `nextcode_demo.db` содержит учебный каталог, цитаты, достижения, аккаунты,
локальные сессии, успешные ответы и завершения уроков. Пароли хранятся как PBKDF2-хеши
с отдельной случайной солью. Начальные данные создаются при первом открытии базы.
Начисление опыта и достижений атомарно; повторное завершение урока не даёт повторной награды.
Данные разных аккаунтов разделены. Серия занятий считается по календарной дате устройства.

Демо не запрашивает разрешение INTERNET и не обращается к API. Резервное копирование
отключено. Русский — единственный доступный язык учебного каталога в этой версии.
Данные не синхронизируются с сервером. Удаление приложения или очистка его данных
удаляет локальные аккаунты и прогресс. Для повторного показа с нуля удобнее создать новый аккаунт.

## Проверки

```bash
bash gradlew assembleFullDebug assembleDemoDebug testFullDebugUnitTest testDemoDebugUnitTest
```

Дополнительные тесты demo проверяют прохождение всех 18 заданий, последовательную разблокировку,
идемпотентное начисление XP и достижений, сохранение после открытия базы заново,
повторный вход, разделение аккаунтов, редактирование профиля, неверный пароль,
дубли логинов, чужие задания и некорректные сессии. Общие UI-тесты выполняются для обеих сборок.
